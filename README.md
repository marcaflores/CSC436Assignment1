# Marc Flores Mendoza — Personal Portfolio

CSC436 Project 1: Static Foundations. A personal portfolio site built with semantic HTML, CSS Grid and Flexbox, and vanilla JavaScript — featuring an About/Education/Skills/Experience overview, a projects showcase with image carousels, a contact page with a working form, an embedded resume viewer, and a light/dark theme toggle.

## Live Site

https://marcfloresdev.netlify.app/

## Run Locally

This is a static site (HTML/CSS/JS) with no build step.

1. Clone the repo:
   ```
   git clone https://github.com/marcaflores/CSC436Assignment1.git
   cd CSC436Assignment1
   ```
2. Install dev dependencies (just `live-server`):
   ```
   npm install
   ```
3. Start the local server:
   ```
   npm start
   ```
4. Open the URL `live-server` prints in your terminal (defaults to `http://127.0.0.1:8080`).

You can also skip the server and open `index.html` directly in a browser.
